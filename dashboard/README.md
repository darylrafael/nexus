# Nexus Dashboard

Local dashboard for the Nexus IHSG market-intelligence pipeline. It displays evening-review artifacts, learning lessons, and SQLite session counts generated by the Python application.

## Run locally

From this directory:

```bash
npm install
npm run dev
```

Open [http://127.0.0.1:3001](http://127.0.0.1:3001). The dashboard expects to sit beside the Python project so it can read `../runs` and `../nexus_sessions.db`.

For a portfolio demo closer to production:

```bash
npm run lint
npm run build
npm run start
```

## Data flow

1. The morning pipeline writes a structured prediction to `runs/YYYY-MM-DD/`.
2. The evening review writes `evening_review.json` in the same folder.
3. The `/api/stats` route reads those local artifacts and the read-only SQLite session database.
4. The browser renders performance metrics, the latest review, commodities, and lessons learned.

The app intentionally has no write endpoints and no client-side credentials.

## Demo dataset

For a polished offline portfolio demo, start the dashboard with the tracked demo fixtures instead of your private local runs:

```powershell
$env:NEXUS_DEMO_MODE = "true"
npm run dev
```

Demo mode is visibly labeled in the UI. Its market outcomes are sourced from public reports; its forecasts, scoring, and lessons are intentionally illustrative and must not be presented as live backtest results.

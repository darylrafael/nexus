# Source-backed dashboard demo fixtures

These fixtures are deliberately separate from `runs/`, which contains local live pipeline artifacts and is ignored by Git.

The `ihsg_actual`, daily percentage move, and foreign-flow direction are based on the public market summaries linked below. Forecasts, confidence values, accuracy scores, root-cause analysis, lessons, USD/IDR values, and commodity display values are illustrative examples designed to demonstrate the product flow. They are **not** historical backtest claims and must be shown only with `NEXUS_DEMO_MODE=true`.
